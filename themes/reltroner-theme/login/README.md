# Reltroner Studio Keycloak Login Theme

Production-ready Keycloak login theme for Reltroner Studio.

## Identity

- Brand: Reltroner Studio
- Tagline: Build. Learn. Create.
- Theme folder: `reltroner-theme`
- Parent theme: `keycloak`

## Supported Flows

- Login
- Logout confirmation
- Registration
- Forgot password
- Email verification
- Session and information pages
- Error pages

## Assets

The active theme assets are:

- `resources/img/favicon.svg`
- `resources/img/background.svg`

## Styling

The CSS uses centralized Reltroner variables in `resources/css/custom.css` and keeps Keycloak IDs/classes available for compatibility with the parent theme.
